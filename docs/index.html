完整安装说明
  1. 01

    添加工具仓库

    在安装了 VCC 的电脑上，点击上方“添加到 VCC”，并确认添加仓库。

  2. 02

    安装 Zincat

    打开项目的 Manage Project 页面，找到 Zincat 并安装。需要 VRChat Avatars SDK、Modular Avatar 和 NDMF。

  3. 03

    打开 Unity，开始使用

    等待编译完成，在顶部菜单中找到 Zincat。以后有新版本时，通过 VCC 更新即可。

在 VCC 的 Settings → Packages → Add Repository 中粘贴。

i

从旧版升级？你的创作仍在。首次迁移前请备份工程。已有菜单图标、上传封面与个人配置保留在原工程；请保留安装后剩余的 Assets/Zincat 文件夹。部分功能需要单独安装对应插件，详见安装说明。
