# Zincat Lighting 0.4.1

支持 lilToon 与 Poiyomi 的独立光照控制。配置组件与 MA 菜单放在同一个预制体中，Avatar 根对象不需要额外组件。

## 使用

1. 将 `Assets/Zincat/Lighting/Prefabs/Zincat 光照控制.prefab` 拖到角色下面。也可以选中角色，执行 **Zincat → 光照控制**，添加或选中菜单预制体。
2. 在预制体根对象的 **Zincat 光照菜单配置** 中调整三个控制项的范围与默认值。参数前缀、同步设置和排除列表在“高级设置”中。菜单设置自动同步，无需点击更新或生成按钮。
3. Poiyomi 材质会在上传前自动检查：未锁定或未就绪时，自动执行一次材质准备和重新锁定；已就绪的材质直接跳过。也可以提前点击 **准备 Poiyomi 材质**。处理会直接配置角色当前使用的现有材质，恢复完整 Shader、添加光照属性 A 标记，再调用已安装的 ThryEditor 锁定。不会创建专用材质资产或替换 Renderer 引用；共用这些材质的角色也会受到修改，可用 Unity 撤销恢复之前状态。lilToon 无需此步骤。
4. 正常构建即可。自动准备在 NDMF 暂停资源导入之前执行；光照构建阶段另有一次补处理，只有准备失败或处理后仍未就绪才会中止。NDMF 根据当前角色的模型路径生成 FX 动画和 MA 参数，再交给 MA 合并。可展开 **测试**，点击 **生成测试副本**；它也会先自动准备材质，生成的副本默认停用。

预制体可以复制或保存为自己的变体。范围、菜单名称、图标和顺序随预制体保存；动画不预先绑定某一个角色。排除 Renderer 是角色实例的设置，通常不要应用回通用预制体。

## MA 菜单

预制体根对象带 MA Menu Group 和默认的 MA Menu Installer，下面是光照子菜单与三个真正的 MA Menu Item 旋钮。直接修改这些 MA 组件的标签、图标及层级顺序即可；自动同步保留这些编辑和对象引用，菜单里没有提示词。

想通过自己的 MA 菜单引用时，关闭 **自动安装菜单**。在自己的 MA 子菜单上将来源设为对象子项，引用预制体内的 **光照控制** 子菜单对象，就得到三个旋钮；引用预制体根对象的子项则得到光照子菜单入口。

停用配置组件或整个预制体时，构建副本不会安装这套菜单。删除时请删除整个菜单预制体，避免留下 MA Installer。手动准备过的材质状态会保留。

## 三个旋钮

- 最低亮度：默认范围 0～1，初始值 0。
- 最高亮度：默认范围 0～2，初始值 1。
- 环境光颜色影响：默认 0～1，初始值 1；0 减弱灯光染色，1 保留灯光颜色，通过反向映射 Shader 的光照去色属性实现。实际效果取决于 Shader 与世界光照。

Poiyomi 附加光的亮度上限和颜色影响可同步跟随。三个控制可分别关闭，三个同步 Float 预计占用 24 bit，最终预算由 MA/SDK 汇总。

## 更新与分发

同一角色只启用一套光照控制。试用新版前，请移除或停用旧窗口版生成的光照菜单和 `Zincat Lighting Generated` 对象，避免旧参数与新方案冲突。安装更新保留旧版生成资源和配置资产，便于回退；旧配置资产的兼容脚本仅保留数据，不参与运行。

面向 Unity 2022.3，依赖 NDMF 1.14+、Modular Avatar 1.18+、VRChat Avatars SDK 3.x；lilToon、Poiyomi/ThryEditor 另行安装。本包只包含 Zincat 自己的实现和菜单预制体，不包含这些第三方源码或旧 LightAdjuster 的实现、动画、预制体。可以将本包与自己修改的菜单预制体一起分发，依赖仍需另行安装。

处理 Renderer 当前使用的材质，动画换材质不会自动收集。受控光照属性若使用 Poiyomi RA 分槽动画，按钮会拒绝覆盖；应改成 A 或排除对应 Renderer。全部候选材质先校验，再统一处理。按钮失败会恢复本次修改的材质内容，优化器可能留下未使用的生成资源；可一次撤销整次准备。

已在隔离工程验证真实 Unity、lilToon、ThryEditor 锁定接口、完整 NDMF/MA 构建、外部 MA 菜单引用与跨角色预制体适配。Poiyomi 使用属性测试 Shader；实际角色、完整生产 Shader 的视觉效果和 VRChat 上传仍需工程内检查。


## 0.4.1 优化

- 去掉重复的菜单更新、选中菜单按钮和常驻成功提示；测试操作及高级设置默认折叠。
- 材质统计缓存一秒，并在配置、层级、资产或撤销发生变化后刷新。
- 菜单只在需要同步时更新；缺失的菜单组件可修复，名称、图标与排列保持不变。
- 构建时剔除停用的另一套预制体；没有可驱动材质属性的控制项不会留下空旋钮。
- 检查当前 FX 的参数冲突；在高级设置修改前缀即可避开。
- 材质准备失败时不保存其他未修改的资产；一次撤销可恢复整次准备。

## 工程目录

组件、菜单预制体与说明位于 `Assets/Zincat/Lighting`，编辑器代码位于 `Assets/Zincat/Editor/Lighting`。导出 `Assets/Zincat` 时，两部分都会包含。旧版配置兼容代码仅在原工程的 `Assets/Zincat_Legacy/Editor/LightingCompatibility` 中保留；当前预制体方案无需这些旧类型。
