菜单翻译助手 1.3.3（Unity 2022.3）

入口：Unity 顶部 Zincat → 菜单翻译助手。

使用方法
1. 在窗口左侧拖入 Avatar、MA 菜单对象或 VRC 菜单资源；也可在 Unity 选中对象后点击“使用当前选择”。支持多选，范围固定，不会随点击定位而变化。勾选要翻译的 VRC / MA 来源。
2. 点击“复制待翻译内容”，然后直接粘贴到聊天。复制的文本已附带翻译说明。
3. 复制聊天返回的完整翻译代码块，回 Unity 点击“粘贴翻译结果”。
4. 在预览中核对原文与译文。可搜索、勾选、编辑译文、点击“定位”查找菜单资源。
5. 点击“应用勾选的翻译”。

对象管理：窄窗口点击“管理对象”展开列表；每项可“移除”，也可“清空对象”。对象改变后立即刷新对应菜单预览。移除对象会移除相应预览，清空对象会清空全部预览；不会删除 Unity 对象。清空状态会在脚本重编译后保留。

不用手动传文件。没有固定交换文件夹、后台监听或聊天连接。
剪贴板使用 ZMT2 纯文本格式，每行包含“资源标识、原文、译文”三列，以制表符分隔。
不要手动修改条目标识和原文；聊天返回时保留 ZMT2 首行、所有条目及反斜杠转义。
只有有效且勾选的译文会应用。空译文、相同文字、资源缺失、原文不匹配会显示跳过原因。
如果导出后增删或重排菜单，请重新复制菜单再翻译。
预览始终跟随当前翻译对象和 VRC / MA 来源。保留范围内原文未变的译文；范围外译文不导入，原文已变化的译文不导入。没有翻译对象时不能粘贴出预览或应用译文。
错误内容不会覆盖当前对象的有效预览。译文保存在编辑器窗口状态中，可跨脚本重编译保留。

备份与还原
每次应用前，自动在工程根目录 MenuTranslationBackups 文件夹保存还原文件。
展开窗口底部“备份与还原”可以打开备份位置，或读取还原备份。
读取备份后同样先预览、再应用。连续修改时按从新到旧的顺序还原。
同一次 Unity 会话中也支持撤销。

范围
VRC 菜单修改 controls 的 name；MA Menu Item 修改 label（显示名称）。不改物体名、参数、值、图标、菜单连接或动画。
共享同一菜单资源的 Avatar 都会看到更新后的名称。
支持 MA Menu Item、MA Menu Installer 引用的现有菜单、MA Menu Group 引用的其他对象，以及 Menu Item 从其他对象收集子菜单。包含未激活对象，循环引用去重。
MA label 为空时，复制的原文取物体名；应用译文只写 label，不重命名物体。还原时会恢复原来的空 label。
MA 对象采用 Unity GlobalObjectId 标识。未保存的新场景需先保存才能复制。重新粘贴场景对象译文时，对应场景或 Prefab 需打开。
场景对象和 Prefab 编辑模式里的修改会标记为未保存，请自行保存场景或 Prefab；插件不自动保存整个场景，避免把其他编辑一起写入。Project 内直接选择的 Prefab 资源则会保存对应资源。
当前适配工程内 MA 1.18.7 的 label 结构；其他插件在构建时临时生成的文字不保证覆盖。

安装
本工程已直接安装，无需重复导入。
分发时可导入“菜单翻译助手-1.3.3.unitypackage”。手动安装需保持两个 C# 文件都在 Editor 文件夹内。

验证
Unity 2022.3.22f1 引用编译通过；16 项剪贴板检查通过。
15 项对象与预览范围同步检查通过；字体修订版编译通过。
界面统一使用常规字重和 Unity 原生编辑器字体，保留不同字号区分层级。
